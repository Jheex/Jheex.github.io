Dashboard de Vendas & Performance (BI)
Este projeto tem como objetivo consolidar dados de vendas dispersos de sistemas ERPs em uma visualização estratégica e interativa, permitindo a análise rápida de KPIs para tomada de decisões executivas.
Recursos e Destaques:
  • Tratamento e limpeza de dados avançada com Power Query (ETL).
  • Modelagem de dados em esquema estrela (Star Schema).
  • Métricas calculadas em DAX (Margem, Crescimento YoY e Projeção).
  • Filtros dinâmicos por região, segmento de cliente e período.
